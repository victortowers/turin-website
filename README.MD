## Turin Website

This repository contains many of the components used to deploy the website onto Cloudflare Pages, Github Pages
and likely other providers in the future. You can freely access the website at turinflow.com.br, given it is
deployed and available.

**Our Objective**: Make the commute home, less stressful. Using pionnering techniques and multiple years of continuous tracking on our roads, we want to make it more predictable, with early traffic warning systems and accident notifications, live.
