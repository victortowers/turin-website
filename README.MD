## Turin Website

This repository contains many of the components used to deploy the website onto Cloudflare Pages, Github Pages
and likely other providers in the future. You can freely access the website at turinflow.com.br, given it is
deployed and available.

**Our Objective**: Coordinate and take care of your schedules. We take care and keep an eye on traffic so you can make it. Just so you do your best, everyday.

_Note:_ This repository relies on assets hosted by _turinflow.com.br_ or _www.turinflow.com.br_. Fonts are and licensed for commercial use by Google Fonts _(fonts.google.com)_. Please utilize Google's CDN or any other provider instead of the endpoint hosted by Turin Flow. 
We are currently utilizing three fonts: Noto Sans, Google Flex Sans and Space Mono.
